# Source and licensing

The extension's code, tools and the new features guide are provided under
[MIT](LICENSE). The Tallent Edition Sounds are provided under the same terms.

Waldorf's Microwave II/XT/XTk operating system, its disassembly, and its
manuals are not included. Users obtain the official update separately.
The patch holds only this project's code and the addresses of the bytes it
replaces; the patcher applies it to the user's own copy of Waldorf's
update. Patched update files contain Waldorf's code and are local outputs,
not release assets.

This is an independent, unofficial project for the Waldorf Microwave II,
XT and XTk. It is not affiliated with or endorsed by Waldorf.
